# Screen Spec – Review Your Collection

## Purpose
Review selected material, pickup details and the collection journey before confirmation/payment.

## Approved elements
- Back + brand header
- “Review your collection”
- Selected items/categories strip
- Add or edit action
- Pickup address
- Pickup slot
- Journey of your sacred items
- Collection summary
- Important note
- Sticky gold confirm/pay CTA

## Journey
Approved visual concept:
1. Your home
2. Collected by Tirodhan using a human-powered rickshaw
3. Actual resolved receiving kiosk / authorised Delhi receiving point

Where later downstream data is trustworthy, the journey may extend into authorised onward processing.

## Pricing
Pricing is backend-owned and may evolve.
Do not encode a permanent flat-rate assumption.
