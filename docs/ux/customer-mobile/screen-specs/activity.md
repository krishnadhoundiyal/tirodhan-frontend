# Screen Spec – Activity

## Purpose
Show current and past sacred collection journeys.

## Approved elements
- Brand header + current address strip
- “Activity”
- Active / History segmented control
- Current Journey hero card
- Collection date/time/address
- Human-powered collection imagery
- Journey timeline:
  - Booked
  - Collected by Tirodhan
  - Government/authorised kiosk
  - Authorised onward processing
- Past collections
- Based on previous collections
- Bottom navigation

## Product intent
Activity is a journey record, not a bland order-history list.

Activity remains a primary tab and is also linked from Account.
