# Screen Spec – Mobile Login

## Purpose
Start OTP authentication using a mobile number.

## Approved elements
- Brand lockup
- “Welcome to Tirodhan”
- “Continue with your mobile number”
- +91 country code
- Mobile number input
- Gold “Continue” CTA
- Terms & Privacy text below

## Behavior
- Numeric keyboard
- CTA disabled until valid mobile input
- Continue calls backend OTP-start route
