# Screen Spec – Select Pickup Address

## Purpose
Choose an existing pickup address or add/find another.

## Approved elements
- Back + brand header
- “Select pickup address”
- Address/landmark search
- “Use current location”
- Map preview
- Current detected address + Change
- Saved addresses (e.g. Home, Temple, Other)
- Add new address
- Gold “Continue” CTA

## Behavior
- Ask for location permission only after “Use current location”
- Use standard map/current-location behavior
- Saved address selection must be obvious
- Manual address entry/edit remains available
