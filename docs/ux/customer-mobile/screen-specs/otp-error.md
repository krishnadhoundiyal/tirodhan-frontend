# Screen Spec – OTP Verification Error

## Purpose
OTP verification UI including invalid-code state.

## Approved elements
- Brand lockup
- Decorative devotional image near top
- “Verify mobile number”
- Destination mobile number
- Six OTP boxes
- Inline red error message
- Gold “Verify” CTA
- “Resend code” below

## Behavior
- Support OTP autofill where platform permits
- Keep error inline; no blocking modal
- Resend uses the backend OTP flow
