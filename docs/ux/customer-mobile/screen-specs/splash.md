# Screen Spec – Splash

## Purpose
Brand-led opening screen while session state initializes.

## Approved elements
- Gold lotus-jyoti symbol centered
- Tirodhan wordmark
- Thin gold divider with centered diamond
- Hindi tagline:
  - श्रद्धा से संग्रह
  - सम्मान से प्रस्थान
- Thin loading indicator near the bottom

## Rules
- Hindi must be live text.
- Keep the screen minimal.
- Do not add onboarding copy.

## Behavior
After bootstrap:
- authenticated → Home
- unauthenticated → Mobile Login
