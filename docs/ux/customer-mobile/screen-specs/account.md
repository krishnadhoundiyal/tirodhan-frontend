# Screen Spec – Account

## Purpose
Customer profile, preferences, support, legal and navigation to account-level capabilities.

## Approved elements
- Brand header + current address strip
- “Account”
- Profile summary/edit
- My Account:
  - Saved Addresses
  - Payment Methods
  - Favourites
  - Activity
- Support:
  - Help & Support
  - Share Feedback
- Preferences:
  - Language
  - Notifications
- About:
  - About Tirodhan
  - Terms & Conditions
  - Privacy Policy
- Logout
- Bottom navigation

## Important rule
Activity must appear within Account even though Activity is also a primary navigation section.
