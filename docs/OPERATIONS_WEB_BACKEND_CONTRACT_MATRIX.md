## Integration gaps and refresh policy

No verified APIM web adapter; no manager overview aggregate; no global active
assignments/offers or route discovery list; no receiving-point handover validation
or collection-completion projection in the operational reads; no V1 incident
resolved history or region filters. Region configuration identities, known-booking
assignment lineage and paginated immutable custody transfers are supported and
implemented through the business-history reads above.
No existing manager-browser event/WebSocket contract was found. This increment
uses finite, explicit reads on navigation/selection and manual refresh, with no
polling, background fanout, operational writes or fabricated live metrics.
V1 counts are explicitly counts of the returned capped slice, never totals.
V2 flags must be verified against deployment configuration before live use.
