# Customer Web public content inventory

All public routes are complete build-time HTML, available without JavaScript. Copy follows frozen architecture Category 1, approved Customer Mobile tone/bilingual sentiment and design category groupings. New explanatory copy is a reviewable frontend draft; this implementation is not editorial approval or deployment.

Metadata: unique title/description, Open Graph title/description/type, one h1, semantic headings. No invented structured business data, ratings, canonical host, sitemap origin or absolute social-image URL. Approved public origin remains a publishing prerequisite.

Design: cream #F8F5EF, text #111111, muted #6B6B6B and gold #C58A3A direction with darker readable accents; Georgia serif display, self-hosted Inter UI and Tiro Devanagari Hindi. Original SVG has descriptive title; redundant brand ornament is decorative. Fonts retain SIL OFL licenses. No external photo/CDN fabrication or sibling-source imports.

Desktop editorial hero and journey adapt to tablet/mobile; native details navigation/FAQs work without scripts. Forms have labels, bounded inputs, visible keyboard focus, optional label/default choice, manual address entry and focused form headings. Archive uses inline confirmation, not a modal. Private navigation focuses account heading. Skip link, loading/empty/error/live status regions and reduced-motion support are present.

Chrome observations: nine public pages with JavaScript disabled, production private gate/noindex, keyboard skip link/mobile menu and no Home/account overflow at 390/768/1440px. See implementation report for screenshots/evidence. Not a formal screen-reader audit, editorial approval or real-gateway acceptance.
