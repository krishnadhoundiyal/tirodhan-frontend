## CW-11 routing contract for the selected host

The host must serve the existing prerendered public routes normally. Unknown public paths return a genuine 404, rather than an HTTP 200 Home fallback. Serve build assets with correct MIME and reviewed immutable caching only for hashed assets.

For `GET` and `HEAD /account/collections/{valid UUID}` (and optional trailing slash), route to the static `/account/index.html` entry with HTTP 200 and preserve the requested browser URL. The fallback is limited to private account routes; never turn unknown public URLs into a successful account/Home response. Serve private HTML with reviewed private/no-store policy, noindex/nofollow, correct HTML MIME and the approved security headers. It must contain no per-customer/request prerendered state or credentials. A UUID is a navigation identifier, not authorization: the client remains gated and fetches only a backend-owned detail after CUSTOMER admission. Static assets must not be rewritten to account HTML.

Deployment test cases: owned UUID directly opened and reloaded; signed-out and unavailable-auth gate; random/not-owned UUID denied by backend; logout/changed-account reload; trailing slash; HEAD; unknown public route; cache/CDN roundtrip; query/fragment must not inject/echo data into HTML or bypass admission. Archive the selected host's actual routing/header configuration and redacted responses/screenshots. Exact provider syntax is deliberately not invented before hosting selection/approval.
